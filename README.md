# Stock-Visualizer
Project for the University of Missouri-Columbia's INFOTC-4320 - Software Engineering class.
Project by Jackson Pozzi, Shane Connor, Miles Baker, and Molly Hitt

# Overview
This project is a visualizer for stocks information. Specifically, the user inputs a specific stock, graph type, time series function, and start/end date, whereas the application will take that data and transform it into a graph via the use of the Alpha Vantage API.
